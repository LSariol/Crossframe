# Crossframe

A browser extension that links [Warframe Wiki](https://wiki.warframe.com), [Warframe.Market](https://warframe.market), and [Overframe](https://overframe.gg) together: when you're looking at a supported item on one of these sites, Crossframe adds buttons to jump straight to that same item on the others.

Project documentation is being built up alongside the implementation; see `docs/` for details as they land.
